DISCIPLINA - ALGORITMOS E ESTRUTURA DE DADOS

• Algoritmos e Estrutura de Dados

Um problema computacional é aquele que pode ser resolvido por um computador a partir de dados de entrada, que são processados para gerar uma saída. Para resolver esse problema, utiliza-se um algoritmo, que é uma sequência finita, organizada e sem ambiguidades de instruções. Um algoritmo é considerado correto quando produz a resposta certa para qualquer entrada válida. Como um mesmo problema pode possuir diferentes algoritmos, é importante realizar a análise de algoritmos, comparando as soluções antes da implementação para identificar a mais adequada. Os principais critérios de análise são:

Correção: verificar se o algoritmo sempre gera o resultado esperado.

Eficiência: medir o consumo de recursos computacionais, principalmente tempo de execução e uso de memória, considerando o tamanho da entrada e a quantidade de operações básicas realizadas.

O estudo de algoritmos e estruturas de dados busca desenvolver soluções que sejam não apenas corretas, mas também eficientes. As estruturas de dados, como vetores, listas, pilhas, filas e árvores, organizam e armazenam os dados de forma que os algoritmos possam manipulá-los com melhor desempenho.

Os principais conceitos estudados incluem:

• definição de problemas e desenvolvimento de soluções;
• construção e análise de algoritmos;
• fundamentos de programação;
• técnicas de resolução de problemas;
• uso de estruturas de dados para organizar informações;
• modularização do código por meio de funções e procedimentos.

Em síntese, algoritmos e estruturas de dados constituem a base da programação, permitindo criar programas corretos, organizados e eficientes para resolver problemas de diferentes níveis de complexidade.

• Introdução à disciplina

Algoritmos são conjuntos de instruções passo a passo para resolver um problema, enquanto Estruturas de Dados (ED) são formas organizadas de armazenar e organizar informações na memória. Juntos, eles determinam a velocidade, o consumo de memória e a eficiência de um programa de computador.

Estruturas de Dados (ED) são os blocos de construção usados para organizar os dados. Elas determinam a rapidez com que você pode inserir, buscar ou deletar uma informação.

Lineares: os elementos estão em uma sequência direta.

• Arrays (Vetores): elementos em posições contínuas de memória.
• Listas Ligadas (Linked Lists): elementos espalhados na memória onde cada um aponta para o próximo.
• Pilhas (Stacks): funcionam no sistema LIFO (Last In, First Out).
• Filas (Queues): funcionam no sistema FIFO (First In, First Out).

Não Lineares: os dados são organizados de forma hierárquica ou interconectada.

• Árvores (Trees): estruturas hierárquicas, como pastas e subpastas.
• Grafos (Graphs): redes de dados interconectados, como redes sociais e rotas.
• Tabelas Hash (Hash Tables): pares de chave-valor que permitem buscas rápidas.
