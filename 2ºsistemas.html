DISCIPLINA - ALGORITMOS E ESTRUTURA DE DADOS

• Algoritmos e Estrutura de Dados

Um problema computacional é aquele que pode ser resolvido por um computador a partir de dados de entrada, que são processados para gerar uma saída. Para resolver esse problema, utiliza-se um algoritmo, que é uma sequência finita, organizada e sem ambiguidades de instruções. Um algoritmo é considerado correto quando produz a resposta certa para qualquer entrada válida. Como um mesmo problema pode possuir diferentes algoritmos, é importante realizar a análise de algoritmos, comparando as soluções antes da implementação para identificar a mais adequada. Os principais critérios de análise são: Correção: verificar se o algoritmo sempre gera o resultado esperado. Eficiência: medir o consumo de recursos computacionais, principalmente tempo de execução e uso de memória, considerando o tamanho da entrada e a quantidade de operações básicas realizadas (comparações, atribuições, operações aritméticas e lógicas). O estudo de algoritmos e estruturas de dados busca desenvolver soluções que sejam não apenas corretas, mas também eficientes. As estruturas de dados (como vetores, listas, pilhas, filas e árvores) organizam e armazenam os dados de forma que os algoritmos possam manipulá-los com melhor desempenho. Os principais conceitos estudados incluem: definição de problemas e desenvolvimento de soluções; construção e análise de algoritmos; fundamentos de programação; técnicas de resolução de problemas; uso de estruturas de dados para organizar informações; modularização do código por meio de funções e procedimentos. Em síntese, algoritmos e estruturas de dados constituem a base da programação, permitindo criar programas corretos, organizados e eficientes para resolver problemas de diferentes níveis de complexidade.

• Introdução à disciplina

Algoritmos são conjuntos de instruções passo a passo para resolver um problema, enquanto Estruturas de Dados (ED) são formas organizadas de armazenar e organizar informações na memória. Juntos, eles determinam a velocidade, o consumo de memória e a eficiência de um programa de computador. Estruturas de Dados (ED)São os blocos de construção usados para organizar os dados. Elas ditam a rapidez com que você pode inserir, buscar ou deletar uma informação.Lineares: Os elementos estão em uma sequência direta (um atrás do outro).Arrays (Vetores): Elementos em posições contínuas de memória. Excelentes para acesso direto via índice.Listas Ligadas (Linked Lists): Elementos espalhados na memória onde cada um aponta para o próximo.Pilhas (Stacks): Funcionam no sistema LIFO (Last In, First Out). O último a entrar é o primeiro a sair.Filas (Queues): Funcionam no sistema FIFO (First In, First Out). O primeiro a entrar é o primeiro a sair.Não Lineares: Os dados são organizados de forma hierárquica ou interconectada.Árvores (Trees): Estruturas hierárquicas, como pastas e subpastas. Muito usadas em bancos de dados.Grafos (Graphs): Redes de dados interconectados. Usados para mapear redes sociais ou rotas (ex: GPS).Tabelas Hash (Hash Tables): Pares de chave-valor que permitem buscas ultrarrápidas.
