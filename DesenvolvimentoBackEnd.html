Algoritmos e Estruturas de Dados: fundamentos e aplicações na programação

1. Organização Básica de um Computador

Para compreender os fundamentos da programação de computadores, é importante conhecer como um computador é organizado e como seus principais componentes trabalham em conjunto.

De maneira simplificada, podemos entender um computador como um sistema formado por quatro elementos fundamentais:

  • Unidade de entrada;
  • Unidade de saída;
  • Unidade Central de Processamento (CPU);
  • Memória.

1.1 Unidade de Entrada

A unidade de entrada é responsável por permitir que o usuário forneça dados e informações ao computador.

1.2 Unidade de Saída

A unidade de saída é responsável por apresentar ao usuário os resultados obtidos pelo computador.

1.3 Unidade Central de Processamento — CPU

A CPU é responsável pela execução das instruções e pelo processamento dos dados utilizados pelos programas.

1.4 Memória

A memória permite armazenar temporariamente os dados e instruções utilizados durante a execução dos programas.

2. Como os Componentes do Computador Trabalham Juntos

Os componentes de um computador trabalham de maneira integrada para receber, armazenar, processar e apresentar informações.

3. Linguagem de Máquina

No nível mais básico, os computadores utilizam a linguagem de máquina, formada por sequências de bits.

3.1 O que é um bit?

Um bit é a menor unidade de informação digital e pode assumir os valores 0 ou 1.

3.2 Bits e Bytes

Um conjunto de oito bits é tradicionalmente chamado de byte.

4. Representação de Caracteres

Os computadores utilizam sistemas de codificação para representar letras, números e símbolos.

5. Letras Maiúsculas e Minúsculas

Sistemas de codificação utilizam valores diferentes para representar letras maiúsculas e minúsculas.

6. Do ASCII ao Unicode

O Unicode permite representar uma grande variedade de caracteres utilizados em diferentes idiomas.

7. Relação entre Hardware, Memória e Programação

Programar significa criar instruções que permitem ao computador manipular dados e realizar tarefas.

Algoritmos e Estruturas de Dados

Algoritmos: sequência lógica de instruções para resolver problemas e executar tarefas.

Estruturas de dados: formas de organizar, armazenar e manipular informações de maneira eficiente.

Principais estruturas

Arrays, listas encadeadas, filas, pilhas, árvores, grafos e tabelas hash.

Cada estrutura possui características próprias.

Aplicações

Bancos de dados, sistemas de arquivos, redes sociais, sistemas operacionais, mecanismos de busca e inteligência artificial.

Dimensões de complexidade

Estratégia que divide um problema em problemas menores, resolve-os e combina os resultados.

Algoritmo que insere cada elemento na posição correta.

Selection Sort

Algoritmo que procura repetidamente o menor elemento.

Merge Sort

Algoritmo baseado na estratégia de divisão e conquista.

Quick Sort

Algoritmo que utiliza um elemento pivô para dividir os dados.
