INTRODUÇÃO

O que é lógica de programação?

Quando comecei a conhecer a programação, percebi que, antes de aprender uma linguagem de programação, eu precisava aprender a pensar como um programador. Foi nesse momento que compreendi a importância da lógica de programação.

Eu posso definir a lógica de programação como a maneira de organizar meus pensamentos para encontrar soluções para diferentes problemas. Ela me permite dividir um problema em pequenas etapas e determinar uma sequência de instruções que devem ser realizadas para chegar a um determinado resultado.

Para mim, programar é semelhante a seguir uma receita. Quando quero preparar um prato, preciso seguir algumas etapas em uma determinada ordem. Na programação, acontece algo parecido: o computador precisa receber instruções claras, organizadas e na sequência correta.

A lógica de programação também me ajuda a desenvolver o raciocínio lógico. Em vez de tentar resolver um problema de uma única vez, eu posso analisá-lo, identificar suas partes e encontrar uma solução passo a passo.

💡

Exemplo prático

Para verificar se uma pessoa é maior de idade, posso obter sua idade e compará-la com 18.

SE idade >= 18
  MOSTRAR "Maior de idade"
SENÃO
  MOSTRAR "Menor de idade"

Conceito e importância dos algoritmos

Um algoritmo pode ser definido como um conjunto ordenado de etapas utilizado para solucionar determinado problema. Na área da computação, os algoritmos possuem papel fundamental, pois permitem descrever de forma lógica e organizada as instruções que deverão ser executadas por um computador.

Entrada, processamento e saída

O funcionamento de um algoritmo geralmente parte de um conjunto de informações denominado entrada. Após o processamento das informações, o algoritmo produz uma saída, que representa o resultado obtido.

Tipos abstratos de dados

Um tipo abstrato de dado representa um conjunto de informações acompanhado das operações que podem ser realizadas sobre ele, permitindo concentrar a atenção no comportamento dos dados antes de definir sua implementação.

Implementação dos dados

A execução de algoritmos em um computador exige uma representação concreta dos dados. Para isso, são utilizados recursos da linguagem de programação, como tipos de dados, variáveis e operações.

Complexidade computacional

A complexidade computacional permite analisar os recursos necessários para executar determinado algoritmo, principalmente em relação ao tempo de processamento e ao espaço de memória.

Notação O

A notação O permite representar o comportamento de um algoritmo conforme aumenta o tamanho da entrada, auxiliando na comparação entre diferentes soluções.

Recursividade

A recursividade ocorre quando um procedimento realiza uma chamada a si próprio para solucionar partes menores do mesmo problema. É necessário estabelecer uma condição de parada para evitar chamadas indefinidas.
