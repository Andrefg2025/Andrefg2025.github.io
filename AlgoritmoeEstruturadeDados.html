Algoritmos e Estruturas de Dados: fundamentos e aplicações na programação

1. Organização Básica de um Computador

Para compreender os fundamentos da programação de computadores, é importante conhecer, ainda que de forma introdutória, como um computador é organizado e como seus principais componentes trabalham em conjunto.

De maneira simplificada, podemos entender um computador como um sistema formado por quatro elementos fundamentais:

  • Unidade de entrada
  • Unidade de saída
  • Unidade Central de Processamento (CPU)
  • Memória

1.1 Unidade de Entrada

A unidade de entrada é responsável por permitir que o usuário forneça dados e informações ao computador.

  • Teclado
  • Mouse
  • Microfone
  • Câmera
  • Scanner

1.2 Unidade de Saída

A unidade de saída é responsável por apresentar ao usuário os resultados obtidos pelo computador após o processamento dos dados.

  • Monitor
  • Impressora
  • Alto-falantes
  • Projetor

1.3 Unidade Central de Processamento — CPU

A Unidade Central de Processamento, conhecida pela sigla CPU (Central Processing Unit), é responsável pela execução das instruções de um computador.

A CPU executa instruções, realiza cálculos e operações lógicas e coordena diversas atividades necessárias para o funcionamento dos programas.

1.4 Memória

A memória é responsável por armazenar temporariamente os dados e as instruções que estão sendo utilizados pelo computador.

Cada espaço da memória possui um endereço que permite localizar e acessar a informação armazenada.

1.5 Memória RAM e Volatilidade

A memória RAM é utilizada para armazenar temporariamente os dados e programas que estão sendo utilizados pelo computador.

Uma característica importante da RAM é sua volatilidade. Os dados armazenados nela são perdidos quando o computador é desligado.

RAM → armazenamento temporário.

SSD/HD → armazenamento persistente.

2. Como os Componentes do Computador Trabalham Juntos

Os componentes de um computador não funcionam de maneira isolada. Existe um fluxo contínuo de dados e informações entre eles.

Um exemplo simples é uma calculadora.

Entrada → Memória → CPU → Memória → Saída

3. Linguagem de Máquina

No nível mais básico, os computadores utilizam a chamada linguagem de máquina, formada por sequências de bits.

3.1 O que é um bit?

A palavra bit vem de binary digit.

Um bit pode assumir dois valores:

0 ou 1

3.2 Bits e Bytes

Um conjunto de 8 bits é tradicionalmente chamado de byte.

01000001

4. Representação de Caracteres

Os computadores utilizam codificações para representar letras, números e símbolos.

Um exemplo histórico é o ASCII.

A → 65

B → 66

C → 67

5. Por que Existem Diferentes Códigos para Letras Maiúsculas e Minúsculas?

Letras maiúsculas e minúsculas possuem códigos diferentes para que o computador possa diferenciá-las.

6. Do ASCII ao Unicode

O ASCII possui um conjunto limitado de caracteres. Para representar caracteres de diferentes idiomas, foi desenvolvido o Unicode.

O UTF-8 é atualmente uma das formas mais utilizadas de codificação Unicode.

7. A Relação entre Hardware, Memória e Programação

Um computador recebe informações por meio dos dispositivos de entrada, armazena e manipula dados na memória, executa instruções utilizando a CPU e apresenta os resultados por meio dos dispositivos de saída.

USUÁRIO → ENTRADA → MEMÓRIA → CPU → MEMÓRIA → SAÍDA → USUÁRIO

Variáveis e Programação

Uma variável pode ser entendida como um espaço identificado utilizado por um programa para armazenar um determinado valor.

numero1 = 10

numero2 = 20

resultado = numero1 + numero2

Programar significa criar instruções que permitem ao computador manipular dados e realizar tarefas de maneira organizada e automatizada.

Algoritmos são conjuntos de instruções passo a passo para resolver um problema, enquanto estruturas de dados são formas organizadas de armazenar informações.

Juntos, eles determinam a velocidade, o consumo de memória e a eficiência de um programa.

Estruturas Lineares

  • Arrays (Vetores)
  • Listas Ligadas
  • Pilhas
  • Filas

Estruturas Não Lineares

  • Árvores
  • Grafos
  • Tabelas Hash
• Introdução à Análise de Algoritmos

Estudo dos princípios utilizados para avaliar o desempenho dos algoritmos.

• Dimensões de complexidade

A complexidade pode ser analisada considerando o tempo de execução e o espaço utilizado.

• Técnicas de análise

Técnicas utilizadas para analisar o desempenho de diferentes algoritmos.

• Análise de recorrência

Estudo de relações de recorrência utilizadas principalmente na análise de algoritmos recursivos.

• Divisão e Conquista

Estratégia que divide um problema em problemas menores, resolve-os e combina os resultados.

• Algoritmos de Ordenação

Algoritmos utilizados para organizar dados segundo determinado critério.

• Insertion Sort

Algoritmo de ordenação que insere cada elemento na posição correta dentro da parte já ordenada.

• Selection Sort

Algoritmo que procura repetidamente o menor elemento e o coloca na posição correta.

• Merge Sort

Algoritmo baseado na estratégia de divisão e conquista.

• Quick Sort

Algoritmo de ordenação que utiliza um elemento pivô para dividir os dados.

• Listas

Estruturas utilizadas para armazenar conjuntos de elementos de maneira organizada.

• Pilhas

Estrutura baseada no princípio LIFO.

• Filas

Estrutura baseada no princípio FIFO.

• Árvores

Estruturas não lineares organizadas de forma hierárquica.

• Árvores de Pesquisa Binária

Árvores binárias organizadas de forma que os elementos menores ficam à esquerda e os maiores à direita.
