DISCIPLINA - ALGORITMOS E ESTRUTURA DE DADOS
INTRODUÇÃO À PROGRAMAÇÃO

Um algoritmo pode ser compreendido como uma sequência organizada de procedimentos destinada a solucionar determinado problema. No contexto da computação, sua elaboração possui grande relevância, pois os problemas que serão executados por um computador precisam ser descritos de maneira sistemática e precisa. Neste contexto, o estudo dos algoritmos envolve dois aspectos fundamentais: a correção e a eficiência.

A correção está relacionada à capacidade de o algoritmo produzir a solução esperada para o problema proposto. Para comprovar que um procedimento está correto, podem ser utilizadas demonstrações matemáticas que validem seu funcionamento. Já a análise de eficiência busca identificar quanto de recurso computacional é necessário para sua execução, considerando principalmente o tempo de processamento e a quantidade de memória utilizada. Essa avaliação é feita a partir da observação e do estudo do comportamento do algoritmo diante de diferentes situações.

Todo algoritmo recebe determinadas informações como entrada e, a partir delas, realiza uma sequência de operações até produzir uma saída, que corresponde à solução ou ao resultado esperado. Durante essa execução, diferentes dados podem ser criados, modificados e organizados. Quando esses dados são agrupados e manipulados de acordo com características e operações bem definidas, podem ser representados por meio de um tipo abstrato de dado. Esse conceito reúne um modelo matemático e as operações que podem ser realizadas sobre ele.

Os algoritmos são normalmente elaborados considerando esses tipos abstratos de dados. Entretanto, para utilizá-los em uma linguagem de programação, é necessário transformar os modelos conceituais em representações que possam ser processadas pelo computador. Para isso, são utilizados os tipos de dados e as operações disponibilizadas pela linguagem escolhida. A maneira pela qual o modelo matemático é organizado e armazenado no computador corresponde à utilização de uma estrutura de dados.

As estruturas de dados podem apresentar diferentes formas de organização e diferentes maneiras de realizar operações sobre seus elementos. Cada estrutura possui determinadas regras que orientam como os dados devem ser armazenados, acessados ou modificados. Essas características são responsáveis por definir e diferenciar uma estrutura de outra.

O estudo das estruturas de dados está diretamente relacionado ao desenvolvimento e à análise de algoritmos. A escolha da estrutura mais apropriada para um determinado problema depende da compreensão de como seus dados podem ser manipulados de forma eficiente. Por essa razão, conhecimentos sobre complexidade computacional são fundamentais para avaliar se determinada estrutura atende adequadamente às necessidades de uma aplicação. A preocupação com o desempenho dos algoritmos, portanto, influencia tanto a seleção quanto a forma de apresentação das estruturas de dados.

Neste capítulo são apresentados os principais conceitos e recursos de notação que serão utilizados posteriormente. Inicialmente, é apresentada a linguagem empregada na descrição dos algoritmos. Em seguida, são introduzidos os fundamentos da recursividade, uma técnica presente em alguns dos procedimentos abordados. Também é apresentado o conceito de complexidade computacional, utilizado para analisar o desempenho dos algoritmos em relação aos recursos necessários para sua execução.

Para representar matematicamente o crescimento do custo de execução de um algoritmo, utiliza-se, entre outras ferramentas, a notação O, que permite expressar seu comportamento em função do tamanho da entrada. Por fim, é introduzida a ideia de algoritmo ótimo, relacionada à obtenção de soluções que apresentam o melhor desempenho possível dentro das condições estabelecidas para determinado problema.

Algoritmos e Estruturas de Dados

Algoritmos: sequência lógica de instruções para resolver problemas e executar tarefas.

Estruturas de dados: formas de organizar, armazenar e manipular informações de maneira eficiente.

Principais estruturas

Arrays, listas encadeadas, filas, pilhas, árvores, grafos e tabelas hash.

Cada estrutura possui características próprias.

Aplicações

Bancos de dados, sistemas de arquivos, redes sociais, sistemas operacionais, mecanismos de busca e inteligência artificial.

Dimensões de complexidade

A complexidade considera principalmente o tempo e o espaço utilizados por um algoritmo.

Divisão e Conquista

Estratégia que divide um problema em problemas menores, resolve-os e combina os resultados.

Insertion Sort

Algoritmo que insere cada elemento na posição correta.

Selection Sort

Algoritmo que procura repetidamente o menor elemento.

Merge Sort

Algoritmo baseado na estratégia de divisão e conquista.

Quick Sort

Algoritmo que utiliza um elemento pivô para dividir os dados.

Pilhas

Estrutura baseada no princípio LIFO.

Filas

Estrutura baseada no princípio FIFO.

Árvores

Estruturas não lineares organizadas hierarquicamente.
