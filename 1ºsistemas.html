1º Sistemas

O curso de Desenvolvimento de Sistemas no 1º ano tem como objetivo apresentar os fundamentos da área de tecnologia da informação. O aluno começa a entender como funcionam os sistemas computacionais, lógica de programação e os primeiros conceitos de desenvolvimento de software.

Durante esta etapa, são estudados temas como algoritmos, estruturas básicas de programação, introdução a linguagens como HTML, CSS e JavaScript, além de noções de banco de dados e funcionamento da internet.

O foco principal é construir uma base sólida para que o estudante possa evoluir nos próximos anos, desenvolvendo projetos simples e entendendo a lógica por trás dos sistemas digitais que usamos no dia a dia.
